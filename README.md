## 📖 About

Libre Hardware Monitor is an open source sensor monitoring utility for Windows, maintained as a community continuation of the original Hardware Monitor project. It polls the embedded controllers, SMBus chips, CPU thermal diodes and GPU sensors exposed by your hardware, then displays every reading in a single tree so you can see temperatures, fan speeds, voltages, power draw and clock rates side by side. Recent builds add newer motherboard and GPU sensor support, improved reporting for hybrid CPUs and a portable mode that stores configuration next to the executable.

The application runs with a lightweight background service or in standalone mode, supports global hotkeys, tray icon readings, CSV and XML logging, and threshold alerts when a sensor crosses a limit you define. If you came looking for a Libre Hardware Monitor download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** PC builders checking thermal paste and airflow · overclockers validating stability runs · IT technicians diagnosing failing fans · home server owners watching drive temperatures · laptop users tracking thermal throttling · hardware reviewers collecting sensor logs · anyone curious about what their components are doing under load.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Sensors show zero or dashes | Run the app as administrator so it can reach the sensor driver. |
| Missing fan or voltage entries | Check that your motherboard chip is supported and update the app. |
| Readings freeze after sleep | Close and reopen the app, or restart the background service. |
| Log file stays empty | Confirm the output folder exists and is writable. |
| Tray icon missing | Enable tray mode in settings and check the hidden icons area. |
| High CPU use while monitoring | Increase the polling interval in settings. |
